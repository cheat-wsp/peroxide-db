Time Splitter

Outros fonte original

Description

The Time Splitter is a consumable item purchasable from Dr. Hydrogen in his pocket realm for 2,200. A more powerful variant, the Charged Time Splitter, is also available for 5,500.

It is used to summon Time Bubbles, which allow the player to fight Raid Bosses. Completing a Raid guarantees a minimum of 9 Time Relics, or 19 when using the Charged Time Splitter. It can summon the following raids: Aizen Raid, Ulquiorra Raid, Starrk Raid, Nnoitra raid, Byakuya Raid and Yamamoto Raid, depending on the current world. For more information on raids, see Time Bubbles.

Notes

  • Using the Charged Time Splitter summons a Distorted Raid instead of a regular one.
