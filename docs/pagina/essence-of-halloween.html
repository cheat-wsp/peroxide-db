Essence of Halloween

Eventos fonte original

Obtained by turning in 120 Wungus at the Harvester NPC ( Halloween Event 2023 Exclusive )

With this Item you can get a random Halloween themed Skill skin.

If you want to see the current Skill skins in the game, check the Skill Skins tab.

It looks like an item knowledge but color swapped to be purple and orange.

NOTE: YOU EQUIP THESE SKILLS IN THE SKILL MENU THAT YOU OPEN BY PRESSING N
