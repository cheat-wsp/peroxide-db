Gargan

Gargan is a npc that can (for 200 yen) make appear a hueco mundo portal and (for 150 yen) a portal for the menos forest.

If you are an Hollow/Arrancar, this npc is useless because you already have both of the portals (right click for menos forest and left click for hueco mundo) and if you are not a Hollow/Arrancar you can just ask in the chat in game if someone can open a portal for you.
