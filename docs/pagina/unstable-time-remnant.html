Description

The Unstable Time Remnant is a Godly Item. Using it will open a small menu, allowing you to choose between a random Ultimate Crystal, a random Legendary Skill, or a random Godly Accessory. Being a different loot pool than the Stable Time Remnant, but can share some Godly Accessorys
