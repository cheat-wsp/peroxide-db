Pure Hogyoku

Hollow fonte original

"A mere imprint of a legend, is terrible echoes still tremoring even unto this hourglass."

Description

The Pure Hogyoku also known as a True Hogyoku (short: True Hog or Pure Hog). The Pure Hogyoku looks like a normal Impure Hogyoku with the difference that it is purple and has a purple glow.

Obtainment

  • Starrk raids (5% normal/10% distorted)
  • S- Rank Invasions (drop rate indeterminate)
  • Storm Delving

Usage

  • Used to start the Horn of salvation questline.
  • Using it will give max Vizard mastery.
  • Using it on Adjuchas will give you 1k points.

Trivia

The developers have stated: "this will be used for new paths in the future". If the Pure Hogyoku is used with Vastorage the Pure Hogyoku will destroy itself, since it was already stated before by the developers themselves that you can have Vrage or Hos not both.
