Hair Rat (Donation)

Outros fonte original

Description

Hair Rat is an NPC where you can spend robux.

Usage

  • Donating (ranging from 1 to 100000 robux)
  • Spawning Time Gate Early. (10k robux)
  • Buying a custom name. (soul lords only + 5k robux)

Location

In the small playground next to the Karakura Hospital.
